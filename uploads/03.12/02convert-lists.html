✅ Catalog Importer for MistGoat App

🔹 Formato gerado: { label = "...", url = "...", media_type = "...", category = "..." }
🔹 O campo label vem sem [""] — apenas o nome puro.
🔹 O campo media_type é inferido pela extensão da URL (.mp4 → video, .png/.jpg → image).
🔹 A categoria é opcional — se deixar em branco, não será adicionada.
